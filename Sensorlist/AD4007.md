# 1. 通信基础接口 (Communication Interface)
- **支持的协议**: SPI / QSPI / MICROWIRE / DSP 兼容串行接口 (不支持 I2C 与 UART)。
- **SPI 模式配置**: 必须配置为 CPOL = 0, CPHA = 0。
- **最大时钟频率 (SCK)**: 
  - VIO ≥ 2.7V 且开启 Turbo 模式：最大 100 MHz (最小周期 9.8 ns)。
  - VIO ≥ 2.7V 且关闭 Turbo 模式：最大 93 MHz。
  - VIO < 2.7V 时最高速率降至约 80 MHz (最小周期 12.3 ns)。
- **转换时间 (tCONV)**: 典型值 290 ns (范围: 270 ns ~ 320 ns)。
- **底层物理层参数**:
  - 核心电源 (VDD): 1.71V ~ 1.89V (典型 1.8V)。
  - 逻辑接口电源 (VIO): 1.71V ~ 5.5V。
  - 参考电压 (VREF): 2.4V ~ 5.1V。

# 2. 核心寄存器映射表 (Core Register Map)
```c
/* AD4007 无传统寻址寄存器，仅包含一个8位配置寄存器，通过16位SPI指令访问 */
/* SPI 通信格式: [8-bit 指令] + [8-bit 寄存器数据] */

#define AD4007_CMD_WRITE_CONFIG 0x14 // 默认写入指令 : 写入配置寄存器 (WEN=0, R/W=0, 010100)
#define AD4007_CMD_READ_CONFIG  0x54 // 默认读取指令 : 读取配置寄存器 (WEN=0, R/W=1, 010100)
```

# 3. 关键位域与掩码 (Key Bitfields & Masks)
```c
/* 配置寄存器 (Configuration Register) 位域与掩码宏定义 */

#define AD4007_CFG_STATUS_EN_MASK    (1 << 4) // [0] : 启用状态位追加到转换数据后 (0:禁用, 1:启用)
#define AD4007_CFG_SPAN_COMP_MASK    (1 << 3) // [0] : 量程压缩模式 (0:禁用, 1:启用)
#define AD4007_CFG_HIGHZ_EN_MASK     (1 << 2) // [0] : 高阻抗模式 (0:禁用, 1:启用)
#define AD4007_CFG_TURBO_EN_MASK     (1 << 1) // [0] : Turbo 模式 (0:禁用, 1:启用)
#define AD4007_CFG_OV_CLAMP_FLAG     (1 << 0) // [1] : 输入过压钳位标志位 (只读粘滞位, 0:曾发生过压, 1:正常)

/* ------ 复杂位域详细中文功能说明 ------ */
/*
 * 高阻抗模式 (High-Z Mode):
 * 显著降低开关电容采样时产生的非线性电荷回馈，降低输入电流至亚微安级。
 * 使得可以采用低功耗、低带宽的运放驱动ADC。仅适用于 <100kHz 的输入频率；多路复用时必须禁用。
 *
 * 量程压缩 (Span Compression):
 * 将实际能够采样的输入满量程范围压缩至 ±0.8 * VREF。
 * 设计用于单电源运放系统中，为驱动放大器提供 10% 的电源轨余量（Headroom/Footroom），防止信号在运放端削顶。
 *
 * Turbo 模式 (Turbo Mode):
 * 允许在使用较低 SPI 时钟频率的情况下维持最大吞吐率。开启后，SPI 读取的数据实际上是"上一次"的转换结果。
 * 由于利用了当前采集阶段的时间来读出旧数据，因此增加了读取窗口的时间。
 */
```

# 4. 状态机与初始化流程 (Initialization Sequence)
- **Step 1: 硬件上电与复位 (Power-up & Wait)**
  - `寄存器地址 -> 无 (物理供电)`
  - `功能描述`: 施加 VDD 与 VIO，稳定后设备自动进入采集阶段 (Acquisition Phase)。
  - `延时要求`: 无需软件复位指令。上电后，根据 CNV 和 SDI 的电平状态，SDO 会自动处于 Low 或 High-Z 状态。

- **Step 2: 写入配置寄存器 (Configure ADC)**
  - `寄存器地址 -> 无 (发指令 0x14)`
  - `写入值`: `0x14` 后跟 `[配置字节]`（如开启 High-Z 模式写入 `0x04`）。
  - `功能描述`: 配置 ADC 的工作模式（High-Z / Turbo / 状态位使能等）。
  - `延时要求`: 必须拉低 CNV 后在 SCK 时钟下写入 16-bit，完成后拉高 CNV。拉高后必须等待最小 `tQUIET2` (60ns)。

- **Step 3: 触发转换与空负载处理 (Trigger Initial Conversion)**
  - `寄存器地址 -> 无 (硬件引脚控制)`
  - `功能描述`: 发送一个 CNV 上升沿脉冲触发首次转换。如果启用了 Turbo 模式，此时内部管线发生变化，第一次读出的数据无效，必须丢弃。
  - `延时要求`: 保持 CNV 高电平至少等待转换时间 `tCONV` (最大 320ns)。

# 5. 传感参数控制、数据读取与转换逻辑
- **参数控制**:
  - ADC 本身不具备内部 PGA 增益控制，其量程由外部 $V_{REF}$ 电压引脚和内部的 **量程压缩 (Span Compression)** 标志位唯一决定。
  - 通过写入上述位域修改模式，无中间过渡状态，写入配置字节后在下一次 CNV 上升沿生效。
- **典型传感参数配置**:
  - *高频/多路复用场景*: 关闭 High-Z，关闭 Span Compression (配置字节为 0x00 或 0x02仅开启Turbo)。
  - *低功耗/单电源静态高精度场景*: 开启 High-Z 和 Span Compression (配置字节为 0x0C)。
- **读取触发 (Data Ready 判定)**:
  - **硬件中断判定 (推荐)**: 采用带 Busy 指示的 3线/4线 模式。拉高 CNV 开始转换，转换结束后 SDO 引脚会被 ADC 硬件自动拉低，该下降沿可直接连接 STM32 的 EXTI 中断以触发 SPI 接收。
  - **延时判定**: CNV 产生上升沿后，软件阻塞延时或利用定时器延时 `tCONV_MAX` (320ns)，延时到达即判定数据就绪。
- **数据拼接处理**:
  - 数据位宽为 18-bit。
  - **大小端模式**: 大端模式传输 (MSB First)。
  - **对齐与拼接**: 主机使用 24-bit (或 3x8-bit) SPI 传输。高 18 位为纯数据，低 6 位为可配置的状态位（若状态位开启）。必须将接收到的 24-bit 整体右移 6 位。
  - **有符号数处理**: 结果为 18-bit 二进制补码 (Two's Complement)。由于 C 语言没有 18 位整型，必须手动进行符号扩展：如果第 17 位（符号位）为 1，则将高 14 位全部置为 1，强转为 `int32_t` 处理。
- **物理量转换**:
  - 18 位数据表示十进制范围: `-131072` 到 `+131071`。
  - **正常模式 (Span Compression 关闭)** 确切数学公式: 
    $V_{IN} = \text{Code}_{int32} \times \left( \frac{V_{REF}}{131072} \right)$
  - **量程压缩模式 (Span Compression 开启)** 确切数学公式: 
    $V_{IN} = \text{Code}_{int32} \times \left( \frac{0.8 \times V_{REF}}{131072} \right)$
