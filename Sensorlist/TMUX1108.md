
# TMUX1108 开关底层驱动开发核心规范 (极速 GPIO 架构)

本文档定义了 TMUX1108 (8:1 模拟多路复用器) 的底层驱动规范。为配合 100Hz 的 HRTIM 高频激励-采集任务，所有地址切换管脚必须放弃耗时的 `HAL_GPIO_WritePin`，**全面采用 BSRR 寄存器内联函数 (Inline)** 进行极速原子级操作。

## 1. 通信基础接口 (Communication Interface)
- **物理接口**: 并行 GPIO 控制 (无 I2C/SPI 耗时时序)。
- **控制引脚**: 
  - `EN`: 使能控制 (高电平有效，低电平时所有通道高阻断开)。
  - `A0, A1, A2`: 通道选择地址线 (3-bit 寻址，000~111 对应 S1~S8)。
- **逻辑电平**: 1.8V 兼容逻辑，支持失效防护 (Fail-Safe Logic)，最高耐受 5.5V。

## 2. KB / KL / KH 接口定义表
系统中存在三组 TMUX1108，分别负责不同的电桥/信号切换链路。

| 开关组别 | A0 引脚 | A1 引脚 | A2 引脚 | EN 引脚 (使能控制) | 控制方式约束 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **KB (Bridge)** | PB15 | PC6 | PC7 | **PA8** | 地址线：普通 GPIO (极速 BSRR)<br>EN线：**HRTIM1_CHA1 硬件接管** |
| **KL (Low)** | PD8 | PD9 | PD10 | 硬件常高/悬空 | 地址线：普通 GPIO (极速 BSRR) |
| **KH (High)** | PB12 | PB13 | PB14 | 硬件常高/悬空 | 地址线：普通 GPIO (极速 BSRR) |

*注：KH 组的 PB12~PB14 已确认**无需** HRTIM 控制，采用普通 GPIO 极速操作即可。*

## 3. 结构体 TMUX_Channel_t 与控制函数定义
采用标准化的枚举类型定义物理通道：
```c
typedef enum {
    TMUX_CH_S1 = 0, // A2=0, A1=0, A0=0
    TMUX_CH_S2 = 1, // A2=0, A1=0, A0=1
    TMUX_CH_S3 = 2, // A2=0, A1=1, A0=0
    TMUX_CH_S4 = 3, // A2=0, A1=1, A0=1
    TMUX_CH_S5 = 4, // A2=1, A1=0, A0=0
    TMUX_CH_S6 = 5, // A2=1, A1=0, A0=1
    TMUX_CH_S7 = 6, // A2=1, A1=1, A0=0
    TMUX_CH_S8 = 7, // A2=1, A1=1, A0=1
} TMUX_Channel_t;

```

为实现单周期切换，控制函数必须在 `.h` 文件中定义为 `static inline`，函数原型如下：

* `static inline void TMUX_KB_SetChannel(TMUX_Channel_t channel);`
* `static inline void TMUX_KL_SetChannel(TMUX_Channel_t channel);`
* `static inline void TMUX_KH_SetChannel(TMUX_Channel_t channel);`

## 4. KB / KL / KH 初始化流程

1. **时钟使能**: 开启 GPIOA, GPIOB, GPIOC, GPIOD 的外设时钟。
2. **地址管脚配置**: 将 PB15, PC6, PC7, PD8, PD9, PD10, PB12, PB13, PB14 全部初始化为 **推挽输出 (Push-Pull)**，速度配置为 **Very High Speed**，无上下拉。默认输出拉低 (S1通道)。
3. **EN 管脚特殊处理**: PA8 (KB 组 EN) 作为 HRTIM1_CHA1 硬件输出，**绝对不可**在此处作为普通 GPIO 初始化，否则将破坏定时器联动。

## 5. 开关参数控制与相关硬件参数

* **双向导通电阻 ($R_{ON}$)**: 典型值 2.5 $\Omega$。
* **先断后合时序 (Break-Before-Make, BBM)**: 芯片硬件自带先断后合保护。最大切换时间约 23ns。
* **操作建议**: 在 100Hz TIM2 中断内，首先调用内联函数切换 A0/A1/A2 地址，此时由于 KB 组的 PA8(EN) 仍处于低电平（受 HRTIM 硬件保证），切换过程绝对安全。等若干微秒后，HRTIM 硬件自动拉高 PA8(EN) 接入电桥，完美切合 BBM 时序。
